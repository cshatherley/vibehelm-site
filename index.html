VibeHelm 2 · alpha · Windows

One window for your coding agents.

Run Claude Code, Codex, OpenCode, Antigravity, Cline and MiniMax MCode side by side in real terminals, each on its own project folder. VibeHelm shows which agent is working, which has finished and which is waiting for you.

What's in it today

Everything below is in the current alpha build. Screenshots are from the app with demo data.

Vibe Code

Any number of agents in a grid you can split, stack and rearrange. Each card shows the client, the folder, its state and how long it has been in it.

  • States come from the clients' own status reports, shown with an icon and a word, not just a colour
  • A Windows notification when an agent needs you, finishes or fails
  • Closing VibeHelm stops every client. Reopening resumes each conversation
  • Save sets of agents as workspaces and switch between them

The Coordinator

Ask what everyone is doing and get a plain answer. Ask it to pass an instruction to an agent and it drafts the message for you to check before it is sent.

Focus view

Hide everything except the terminals when you want the full screen for the work, with a slim bar that still tells you who needs you.

Collab

Plan a product in small increments and hand tasks to agents. Each task moves across a board from Shape to Verified, and nothing counts as done until a separate QA check has passed it.

Benchmark In testing

Give several agents the same frozen brief in separate folders and compare what each one produced. We use it to decide which model gets which job.
